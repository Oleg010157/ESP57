# Работа на другом компьютере: что делать по шагам

Памятка для человека. Технические подробности и «почему так» — в
[agents-ccs-path.md](agents-ccs-path.md) и
`INVERTOR_CCS/my_Files/C2000Ware_local_patches.txt`.

## Главное в двух строчках

Выражения окна Watch набирать заново долго — их переносят файлом через git.
Всё остальное либо едет с проектом само, либо восстанавливается одним скриптом.

## Перенести выражения Watch

Это единственное, что требует внимания при переходе с машины на машину.

**На той машине, где выражения есть:**

1. окно Expressions → правый клик → **Export**;
2. в диалоге указать путь целиком (удобнее через `Browse...`) — внутрь папки
   проекта, чтобы файл попал в репозиторий:
   `<папка проекта>\INVERTOR_CCS\watch_expressions.json`;
3. проверить, что в файле не просто `[]` — это значило бы, что Watch был пуст
   и экспортировать было нечего;
4. закоммитить и отправить:

```
git add INVERTOR_CCS/watch_expressions.json
git commit -m "Выражения окна Watch"
git push
```

**На другой машине:** `git pull`, затем окно Expressions → **Import** и указать
тот же файл — он уже будет лежать в `INVERTOR_CCS`.

Путь к файлу на каждой машине свой; точную строку печатает
`Tools\Setup-NewPC.ps1 -Check` в пункте «Watch: выражения».

## Первый раз на новой машине

**1. Получить проект:** `git clone` или `git pull`.

**2. Запустить скрипт настройки** из корня проекта:

```
powershell -ExecutionPolicy Bypass -File Tools\Setup-NewPC.ps1 -Check
powershell -ExecutionPolicy Bypass -File Tools\Setup-NewPC.ps1
```

Первая команда только показывает, чего не хватает; вторая чинит. Запускать
можно сколько угодно раз — повторный запуск ничего не портит.

Он накатит патчи в установленном C2000Ware (без них сборка падает на
`SUCCESS`/`FAIL`), создаст конфиг clangd (без него заголовки SDK серые в
редакторе) и допишет ссылки в `CLAUDE.md`.

**3. Открыть проект в CCStudio,** выбрать конфигурацию и собрать:

```
Project -> Build Configurations -> Set Active -> CPU1_RAM (или CPU1_FLASH)
```

**4. Импортировать выражения Watch** — см. выше.

## Что переносится, а что нет

| | переносится | как |
|---|---|---|
| Исходники, линкеры, `.cproject`, `.syscfg` | да | git |
| Конфигурация отладки, настройки редактора | да | git (`INVERTOR_CCS/.theia/`) |
| Выражения Watch | да | Export в файл → git → Import |
| Патчи C2000Ware, конфиг clangd | восстанавливаются | `Tools\Setup-NewPC.ps1` |
| Открытые вкладки, раскладка окон | **нет** | открыть заново, это быстро |
| История разговоров с Claude Code, его память | **нет** | лежит в профиле машины |

## Почему вкладки пропадают и после переименования папки

CCStudio хранит открытые вкладки и выражения Watch не в проекте, а в своей
локальной базе, причём ключом служит **полный путь** к файлу
`K57.theia-workspace`. Поэтому состояние теряется не только при переезде на
другую машину, но и когда папку проекта просто переименовали.

Обойти это можно — держать неизменный путь через junction (`mklink /J`), —
но выигрыш невелик: junction всё равно придётся пересоздавать после
переименования, а между машинами он не помогает вовсе, база-то у каждой своя.
Проверено 30.09.2026: способ рабочий (Theia junction не разворачивает), но
признан не стоящим усложнения. Подробности, если когда-нибудь понадобится, —
в истории коммитов, `88ee3c5`.

Вкладки открыть заново — полминуты. Выражения Watch — долго, поэтому для них
и заведён экспорт в файл, который от путей не зависит вообще.

## Если окно Claude Code пустое

Значит не выполнен вход. Открыть терминал (`Terminal -> New Terminal`) и
запустить `claude` — он проведёт через авторизацию. Переустанавливать
расширение не нужно, дело не в нём.
