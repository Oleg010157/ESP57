## 2. Структура

```
                 предохранитель
 АКБ 40-60 В ──┬──[ F ]──┬──[ главный контактор ]──┬── + звено ──┐
               │         └──[ реле предзаряда ]─R──┘             │
               │                                  конденсаторы  ┌┴──────────────┐
               │                                  звена         │ MOSFET-модуль │
               │                                                │  (H-мост)     │
 минус АКБ ────┴──[ шунт iBat ]─────────────────── − звено ─────┤               │
                                                                └─┬───────────┬─┘
                                                     [ шунт Ia ]──┘           │
                                                          │                   │
                                                    ┌─────┴───────────────────┴─┐
                                                    │ трансформатор 1:n, 50 Гц  │
                                                    └─────┬───────────────────┬─┘
                                                          │      230 В        │
                                                 [ ТТ Ib ]┤  uSec        ┌────┤
                                                          │              │    │
                                                    [ контактор сети ]   │    │
                                                          │  u220        │    │
                                                        сеть / нагрузка ─┴────┘
```

Платы:

Между мостом и трансформатором тока на схеме выше подразумевается синус-фильтр:
рассеяние трансформатора, конденсатор на вторичке и дроссель L2 (раздел 6.8).

Платы — три проекта KiCad в `hardware/`, структура (ревизия 0.1) от 24.11.2026:

1. **k57-power** — силовая плата, медь 2–3 oz: мост (8 × IRF100P218), драйверы,
   конденсаторы звена, шунты с INA240, делители 48 В, предзаряд, катушка
   главного контактора. Снаружи: радиатор, контактор, предохранитель,
   резистор предзаряда.
2. **k57-control** — плата управления, целиком низковольтная: питание и опора
   REF2033, МК, приёмники дифференциальных сигналов с платы 230 В, CAN, ESP32,
   память аварий.
3. **k57-ac** — плата 230 В: синус-фильтр, сетевой контактор, защита,
   трансформатор тока, изолированные датчики напряжения (изоляционный барьер).

Цепи между платами — листы «Разъём к …» в каждом проекте; их списки обязаны
совпадать попарно.

## 4. Расчётные токи

Оценка при КПД 0,93, активной нагрузке, без перегрузки.

| Величина | n = 8,5, сеть 230 В | n = 8,5, сеть 207 В | n = 9,5, сеть 207 В |
|---|---|---|---|
| Ток первички, действующий | 111 А | 123 А | 138 А |
| Ток первички, пик | 157 А | 174 А | 195 А |
| Ток через ключ, действующий (≈ I/√2) | 78 А | 87 А | 97 А |
| Ток вторички, действующий / пик | 13 / 18 А | 14,5 / 20,5 А | 14,5 / 20,5 А |

Ток АКБ: средний 67 А при 48 В, 81 А при 40 В. Однофазный мост забирает
мощность пульсацией 100 Гц, поэтому мгновенный ток АКБ доходит до двух средних,
около 160 А. Действующее значение пульсации 100 Гц — около 50 А. Её несут
АКБ и кабели; конденсаторы звена берут на себя в основном пульсацию частоты
ШИМ.

## 5. Коэффициент трансформатора надо проверить по худшему случаю

Индекс модуляции растёт с напряжением сети и падает с напряжением АКБ. От
значения `mLoad = 0,795` (n = 8,5, 48 В, 230 В, 3 кВт, модель прошивки) он
пересчитан пропорционально. Это оценка: падения в трансформаторе при другом
токе пересчитаны грубо.

| АКБ под нагрузкой | Сеть 230 В | Сеть 253 В |
|---|---|---|
| 48 В | 0,80 | 0,88 |
| 44 В | 0,87 | **0,95** — на пределе |
| 40 В | **0,95** — на пределе | **1,05** — не выходит |

То есть при n = 8,5 разряженная АКБ и высокое напряжение сети вместе не
проходят. Решения, на выбор:

- увеличить n до ~9,5: сходится во всём диапазоне, но ток первички растёт на
  ~12 % (последний столбец раздела 4);
- поднять нижний порог работы АКБ до ~45 В;
- снижать мощность на разряженной АКБ.

Выбор — после того, как будет выбрана АКБ.

## 6. Требования к блокам

### 6.1 Ключи моста: сравнение вариантов

Общие требования: 100 В (для АКБ до 60 В 80 В мало — выбросы при выключении),
доступность у поставщиков из раздела 1.

Оценка потерь: 87 А действующих на место моста (раздел 4, худший столбец для
n = 8,5), сопротивление канала — максимальное по документации × 1,6 на нагрев
кристалла до ~110 °C, плюс 5–10 Вт коммутационных на весь мост (5 кГц).

- Вариант В не снимает главную трудность (150 А по плате) и самый слабый по
  потерям и мёртвому времени. Использовать два плеча из трёх значит, что
  третье стоит без дела, а запараллелить его с одним из двух нельзя: плечи
  станут несимметричными, а это постоянка в трансформаторе.
- Вариант А лучший по потерям и цене, но самый трудный в изготовлении: тепло

- Варианты Г и Б можно усилить, поставив по два ключа на место: Г — ~55 Вт за

### 6.1.1 Выбрано: IRF100P218, по два на место

Данные — из документации Infineon, Rev. 2.1 от 20.01.2020. Значения «тип.» —
типовые; на них опираются только оценки, запас закладывается сверху.

| Параметр | Значение | Условия |
|---|---|---|
| Uси | 100 В | |
| Rси откр | 1,1 тип. / 1,28 макс. мОм | Uзи = 10 В, 100 А, 25 °C |
| Ток, ограничение корпуса | 209 А | |
| RthJC / RthCS (смазка, без изолятора) | 0,27 / 0,24 К/Вт | |
| Uзи предельное / порог | ±20 В / 2,2–3,8 В | |
| Qg / Qgs / Qgd / Qg(th) | 330 / 100 / 65 / 71 нК | 50 В, 100 А, 0–10 В |
| Плато Миллера | 4,3 В | |
| Внутреннее сопротивление затвора | 0,6 Ом | |
| td(on) / tr / td(off) / tf | 50 / 110 / 170 / 120 нс | 50 В, 100 А, Rз = 2,7 Ом, **один ключ** |
| Диод: Uпр / trr / Qrr | ≤ 1,2 В / 110 нс / 280 нК | 100 А |

**Потери и тепло.** На прибор ~4 Вт проводимости + ~1 Вт коммутации, ~40 Вт
на мост. Перепад «кристалл — радиатор» при изолирующей прокладке
(RthJC 0,27 + прокладка ~0,3–0,5 К/Вт) — около 4 К. То есть радиатор может
греться почти до 100 °C. Требование к радиатору: ≤ 1 К/Вт при 40 Вт, чтобы
при 40 °C снаружи он был не горячее 80 °C. [?] С учётом шунтов (3–4 Вт) и
прочего — уточнить при компоновке.

**Затвор.** У каждого из двух параллельных ключей свой резистор в затворе,
2,2–3,3 Ом: без них параллельные MOSFET склонны к паразитной генерации.
Резисторы — у самых выводов затворов. Заряд на место — 660 нК при 10 В,
мощность драйвера ничтожна (~40 мВт на место на 5 кГц). У TO-247-3 нет
отдельного вывода истока для драйвера: петлю «драйвер — затвор — исток»
делать минимальной.

**Мёртвое время, оценка.** Документация даёт времена для одного ключа. Два
ключа от одного драйвера на 3 А переключаются медленнее; грубо:

- выключение: разряд затвора с 12 В до плато ~140 нс + плато Миллера ~80 нс
  + спад тока ≈ 250–300 нс;
- включение до порога: ~50 нс;
- расхождение задержек UCC27282 — до 7 нс.

С запасом на разброс и нагрев: **начальное значение 500 нс (38 тактов
TBCLK 75 МГц)**, после измерений на железе ожидается 300–400 нс. Ошибка
напряжения от мёртвого времени: 0,48 В при нынешних 2 мкс → ~0,12 В при
500 нс → ~0,08 В при 330 нс. Первое включение нового железа — по-прежнему с
2 мкс (раздел 7, п. 4).

### 6.2 Драйверы затворов

- Неизолированные полумостовые драйверы на 100–120 В с бутстрепом, по одному на
  плечо. Подходит, пока земля управления = минус АКБ. Кандидат — TI UCC27282:
  120 В, ±3 А, расхождение задержек каналов до 7 нс во всём диапазоне
  температур, встроенный бутстрепный диод, блокировка одновременного включения.
  Вывод разрешения есть только в корпусе DRC (10 выводов) — брать его: им
  удобно гасить мост аппаратно.
- Питание драйвера 12 В: годится для всех вариантов 6.1, включая модуль с
  пределом затвора ±15 В.
- Вход 3,3 В. Мёртвое время задаёт МК; блокировку одновременного включения
  в самом драйвере — приветствуется как второй рубеж.
- **Подтягивающие к земле резисторы на входах.** Пока МК в сбросе или
  прошивается, его выводы — входы и висят в воздухе. Ключи в это время
  обязаны быть закрыты.
- Защита от пониженного питания (UVLO) по обоим каналам.
- Затворные резисторы — раздел 6.1.1.
- Бутстреп. Скважность плеча ходит от 0,5 − m/2 до 0,5 + m/2, при
  `mMax = 0,95` нижний ключ открыт не меньше 2,5 % периода — 5 мкс за вычетом
  мёртвого времени. За это время конденсатор бутстрепа подзаряжается каждый
  период. Ёмкость: заряд двух затворов ~0,76 мкК при 12 В, просадка не больше
  0,5 В → не меньше 1,5 мкФ; ставить 2,2–4,7 мкФ X7R на 25 В. Развязка питания
  драйвера — в 10 раз больше бутстрепа, 22–47 мкФ. Сопротивление в цепи
  бутстрепного диода выбрать так, чтобы за 5 мкс конденсатор успевал
  подзарядиться. [?] Проверить расчётом при разработке схемы.

### 6.3 Конденсаторы звена

- Электролиты с низким ESR на 80–100 В плюс плёночные конденсаторы
  непосредственно на выводах модуля.
- Подключение — плоская шина (ламинированная) или плата конденсаторов на
  выводах модуля: индуктивность контура «конденсатор — модуль» определяет
  выброс напряжения при выключении.
- Ток пульсаций — посчитан моделированием однополярной ШИМ моста
  (`sine_invertor2`: плечо A сравнивает 1 − d, плечо B — d, общая несущая
  5 кГц). Ток со стороны звена i = (Sa − Sb)·iвых, разложен на часть на
  частоте ШИМ и среднее за период ШИМ:

  | Режим | Ток звена, всего | Среднее + 100 Гц (АКБ) | Частота ШИМ (конденсаторы) |
  |---|---|---|---|
  | n = 8,5, сеть 230 В, m = 0,80 | 92 А | 77 А | **50 А** |
  | n = 8,5, сеть 207 В, m = 0,85 | 104 А | 90 А | **52 А** |
  | то же, cos φ = 0,8 | 95 А | 79 А | **52 А** |
  | n = 9,5, сеть 207 В, m = 0,80 | 114 А | 96 А | **62 А** |

  Закладывать **60 А** действующих на всю батарею. Пульсацию 100 Гц
  конденсаторы не держат и не должны: на ±1 В при 48 В нужно ~50 мФ. Её
  несут АКБ и кабели.
- Электролиты на 100 В слабые по пульсациям на банку: Nichicon UPW 1000 мкФ
  (18×40) — 1,52 А на 100 кГц, на 60 А их понадобилось бы ~40. Поэтому —
  крупные банки под пайку (snap-in). Пример — Nichicon LGU 100 В: самая
  крупная 4700 мкФ (35×50 мм, LGU2A472MELC), 4,14 А при 120 Гц и 105 °C,
  коэффициент на 10 кГц 1,15 → ~4,8 А. При температуре внутри корпуса ~65 °C
  допустимо больше, но ради ресурса закладывать ~6 А на банку →
  **8–10 банок по 4700 мкФ, 38–47 мФ**. Серию с большим ресурсом и расчёт
  срока службы — [?] при разработке схемы.
- Плёночные 100 В по 2–4 × 10 мкФ у каждого плеча — берут на себя фронты.
- Ёмкость батареи определяет предзаряд (6.4): энергия заряда до 60 В —
  ½·C·U² ≈ 70–85 Дж.

### 6.4 Подключение АКБ

- Предохранитель на плюсе АКБ.
- **Аппаратный предзаряд**: реле или MOSFET с резистором, параллельно им главный
  контактор. Программа управляет последовательностью, но заменить элемент в
  цепи не может — разбор в переписке 24.11.2026: конденсаторы на АКБ
  заряжаются раньше, чем стартует МК.
- Последовательность: предзаряд → напряжение звена ≥ ~90 % от АКБ → контактор.
  Не дождались за отведённое время — авария, а не переход в работу.
- Нужны: 2 GPIO (реле предзаряда, контактор), канал напряжения **звена** (после
  контактора). [?] Второй канал — на клеммах АКБ, чтобы видеть ход предзаряда
  и падение на контакторе.
- TVS-диод на звене. [?] Трудность: при АКБ до 60 В рабочее напряжение TVS
  должно быть ≥ 64 В, а его ограничение на большом токе выходит за 100 В —
  ключи он не защищает. Его задача — гасить выброс от индуктивности кабелей
  при размыкании АКБ под током (например, BMS). Ключи защищает их собственная
  стойкость к лавинному пробою (1050 мДж) и малая индуктивность звена.
- Питание платы управления — от АКБ до контактора (через свой предохранитель),
  иначе МК не сможет управлять предзарядом.
- Главный контактор и предзаряд — **в плюсе** АКБ. В минусе нельзя: минус АКБ —
  земля платы управления, а драйверы нижних ключей опираются на минус звена.
  Разомкнутый ключ в минусе развёл бы эти две земли.

У AMC3330 встроенный изолированный DC/DC — отдельного питания со стороны 230 В
не нужно. Выход дифференциальный: по кабелю с k57-ac он идёт дифференциальной
парой (как и напряжение с нагрузки трансформатора тока Ib), а каскад на ОУ с
центром 1,65 В стоит на плате управления.

**Опорное напряжение — одно на все каналы.** Нуль двуполярного канала — это
1,65 В, и он обязан совпадать с серединой шкалы АЦП. Если середину для INA240
взять делителем от питания 3,3 В (REF1 на питание, REF2 на землю), то 1 %
ухода питания сдвинет нуль на 16,5 мВ — это **4 А** ложной постоянки в канале
Ia при требовании 0,2–0,3 А. Поэтому:

- TI REF2033: два выхода, 3,3 В и 1,65 В, отслеживают друг друга с точностью
  до 6 ppm/°C, точность 0,05 %, до 20 мА. 3,3 В — на VREFHI АЦП (внешний
  опорный режим), 1,65 В — на REF1/REF2 обоих INA240, на смещение
  трансформатора тока и на каскады после AMC3330. Тогда нуль и шкала АЦП
  уходят вместе.
- Остаточный уход нуля Ia после калибровки при включении (прогрев на 40–60 К):
  ~0,15 А от опоры + ~0,06 А от INA240 — укладывается.

### 6.8 Синус-фильтр

Нужен в обоих режимах: в АИН нагрузка получает напряжение конденсатора, в
сетевом фильтр не пускает пульсации ШИМ в сеть.

**Сколько пульсаций без фильтра.** Однополярная ШИМ 5 кГц даёт импульсы
10 кГц, размах пульсаций тока до Uзв·n / (8·f·L), приведённо к вторичке
(Uзв·n = 48 × 8,5 ≈ 408 В):

| Рассеяние трансформатора L1 (к вторичке) | Размах 10 кГц | От пика тока 18 А |
|---|---|---|
| 8 мГн (так в модели, `power_par.c`) | ~1,3 А | ~7 % |
| 4 мГн | ~2,5 А | ~14 % |
| 2 мГн | ~5 А | ~28 % |

**Схема — LCL.** Одного конденсатора мало: жёсткая сеть закорачивает его, и
пульсации идут в сеть.

- **L1** — рассеяние трансформатора. Трансформатора ещё нет, поэтому это
  **требование к нему**: [?] 3–5 мГн, приведённо к вторичке (5–9 % базового
  сопротивления 17,6 Ом). Больше — растёт падение напряжения под нагрузкой и
  требуемый индекс модуляции (раздел 5); меньше — растут пульсации и потери
  в железе трансформатора от тока 10 кГц.
- **C** — плёночный конденсатор для переменного тока (класс X2 или
  специальный для фильтров), 1–2 мкФ, ≥ 275–310 В перем., последовательно —
  демпфирующий резистор. Его узел — точка измерения USEC.
- **L2** — сетевой дроссель 1–2 мГн на 13–15 А действующих, на шасси.

Предварительная прикидка (L1 = 4 мГн, C = 2 мкФ, L2 = 1,5 мГн), [?] —
проверить расчётом и моделью:

| Величина | Значение |
|---|---|
| Резонанс L1–C (АИН, без сети) | ~1,8 кГц |
| Резонанс LCL (на сеть) | ~3,4 кГц |
| Ослабление 10 кГц в сеть, 1 / (ω²·L2·C − 1) | ~0,09: ~0,23 А размаха, ~0,6 % от номинала |
| Ток конденсатора 50 Гц | ~0,14 А (реактивная мощность ~30 вар) |
| Демпфирующий резистор, ≈ 1 / (3·ω_рез·C) | ~8 Ом, ~4 Вт от пульсаций — брать 10 Вт |

Резонанс LCL выше fs/6 = 833 Гц (fs — частота дискретизации контура,
5 кГц): для регулятора по току сетевой стороны это условие устойчивости без
активного демпфирования. Слабая сеть (своя индуктивность) резонанс снижает —
проверить на модели.

Отдельно от синус-фильтра: **ЭМС-фильтр** (синфазный дроссель, X/Y-
конденсаторы) против помех 150 кГц–30 МГц — [?] на k57-ac.

## 7. Что доработать в прошивке под это железо

Не сделано, записано, чтобы не потерялось.

1. **Вывод A1 занят дважды.** Отладочный ЦАП CMPSS1 выводится на A1
   (`1ph_Sin.c:231`), и с того же A1 читается uSec (ADCA SOC3). На модели
   незаметно, на железе АЦП будет читать собственный ЦАП. Один из сигналов
   перенести.
2. **GPIO для контактора сети, реле предзаряда, главного контактора.** Плюс
   автомат предзаряда с аварией по таймауту.
3. **Канал температуры радиатора** и защита по нему.
4. **Мёртвое время** — параметром паспорта силовой части (`power_par`) в
   наносекундах вместо константы 150 в SysConfig. Вместе с ним пересчитать
   `mDCmax` (`power_par.c:66`, обоснован как «мёртвое время просит 0.01») и
   комментарии в `grid_tie.txt` (499, 614), `Task1.cla:299`, `1ph_Sin.c:116`.
5. Коэффициент n и диапазон АКБ — после раздела 5.
5а. **Опорное АЦП — внешнее.** Сейчас в SysConfig
   `asysctl.analogReference = "INTERNAL"`, `analogReferenceVoltage = "1P65"`.
   Под REF2033 (6.5) — переключить на внешнее (VREFHI = 3,3 В). Пороги
   компараторов CMPSS считаются от той же опоры и сохраняют смысл.
6. Мелочь: в комментарии к `sine_invertor2` второе плечо названо EPWM6, код
   пишет в EPwm2Regs.
7. **Синус-фильтр в модели и в регуляторах (6.8).** Сейчас `plant_sim`
   считает `uSecOut = uBridge − Rwind·iSec − Lleak·di/dt`: конденсатора и L2
   нет. Добавить C, демпфирующий резистор и L2; проверить устойчивость
   регулятора тока `grid_tie` (резонанс LCL) и регулятора напряжения АИН
   (резонанс L1–C); перенастроить. uSec теперь — напряжение конденсатора.
   [?] Где ставить трансформатор тока Ib — до или после C — решить вместе с
   регулятором.
