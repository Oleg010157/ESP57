Программа управления однофазным инвертором

Состав
  Program\ICDIBasic.exe   программа
  Program\CanTxFiles\     таблицы параметров окна передачи данных
  ErrorCodes.h            таблица кодов аварий
  invertor.out            файл прошивки; прибор поставляется уже прошитым

Файл ErrorCodes.h должен лежать рядом с папкой Program: программа ищет его там.

Что нужно на компьютере
  Адаптер PEAK PCAN-USB FD с драйвером и .NET Framework 4.8.

Запуск
  Запустить Program\ICDIBasic.exe. Программа сама ищет адаптер и подключается к
  прибору.

Индикация на приборе
  После включения по светодиодам LED1..LED11 бежит огонёк: плата работает.
  LED12 не задействован.

Обновление прошивки
  Меню Update CCS в программе, файл invertor.out из этой папки.
