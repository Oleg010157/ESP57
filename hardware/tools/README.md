# Скрипты, которыми нарисованы схемы K57

Это инструменты, которыми Claude рисует листы схем. Запускать их самому не
нужно.

## Если запустить случайно

Ничего не сломается. Скрипты сами проверяют, можно ли писать:

- `gen_k57.py` (создаёт пустую структуру плат) отказывается работать, если
  хоть на одном листе уже нарисованы компоненты.
- `build_power.py` (рисует листы «Драйверы» и «Мост») отказывается
  перезаписывать лист, если его меняли после прошлого запуска — например,
  поправили в KiCad.

В обоих случаях скрипт пишет «СТОП: …» и ничего не меняет.

## Как это устроено

`generated-hashes.json` — отпечатки листов в том виде, в каком их записал
скрипт. Совпадает отпечаток — лист никто не трогал, его можно перерисовать.
Не совпадает — лист правили, скрипт его не трогает. Файл вести руками не нужно.

| Скрипт | Что делает |
|---|---|
| `gen_k57.py` | Структура (ревизия 0.1): три проекта, верхние листы с блоками, пустые листы с выводами |
| `build_power.py` | Листы «Драйверы» и «Мост» платы k57-power, библиотека `hardware/lib/k57.kicad_sym`, файлы `sym-lib-table` |
| `sch_lib.py` | Общая часть: чтение и запись файлов KiCad, расстановка символов, защита от перезаписи |

Запуск (для Claude):

```
python -I hardware/tools/build_power.py hardware "C:/Program Files/KiCad/10.0/share/kicad/symbols"
kicad-cli sch erc k57-power.kicad_sch
kicad-cli sch export netlist k57-power.kicad_sch
```
