# Скрипты, которыми нарисованы схемы K57

Листы KiCad в `hardware/` созданы этими скриптами. Запускать штатным Python
(`python -I`), KiCad 10 должен стоять в `C:\Program Files\KiCad\10.0`.

| Скрипт | Что делает | Повторный запуск |
|---|---|---|
| `gen_k57.py` | Структура (ревизия 0.1): три проекта, верхние листы с блоками, пустые листы с выводами | **ОПАСНО.** Перезаписывает ВСЕ листы всех трёх проектов, в том числе уже нарисованные. Не запускать поверх заполненных листов |
| `build_power.py` | Листы «Драйверы» и «Мост» платы k57-power, библиотека `hardware/lib/k57.kicad_sym`, файлы `sym-lib-table` | Перезаписывает только эти два листа и библиотеку. Ручные правки этих листов в KiCad при этом пропадут |
| `sch_lib.py` | Общая часть: чтение и запись файлов KiCad, расстановка символов с метками цепей | — |

Запуск:

```
python -I hardware/tools/build_power.py hardware "C:/Program Files/KiCad/10.0/share/kicad/symbols"
```

Правило: лист, который уже правили руками в KiCad, скриптом больше не
перегенерировать — только дополнять в KiCad. Проверка после изменений:

```
kicad-cli sch erc k57-power.kicad_sch
kicad-cli sch export netlist k57-power.kicad_sch
```
